Per eseguire la simulazione è necessario seguire la seguente procedura:



* Aprire il file Roll\_Control\_2DOF\_Matlab
* Runnare il codice
* Sulla Command Window selezionare il file motore disponibile (cliccare 1 per selezionare il primo e unico motore e premere INVIO)
* Attendere la finalizzazione della simulazione su Simulink
* Aprire il file Roll\_Controlo\_2DOF.slx
* Visualizzare i grafici presenti sugli SCOPE a dx
* Aprire il file Animation.m e runnare il file per generare il video-animazione con il modello CAD reale (può richiedere 1-2 minuti in base al processore del PC)
