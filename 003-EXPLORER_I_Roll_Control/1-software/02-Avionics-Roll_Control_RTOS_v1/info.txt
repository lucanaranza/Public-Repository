| State | Transition condition      |
| ----- | ------------------------- |
| 0 → 1 | power stable              |
| 1 → 2 | arm command received      |
| 2 → 3 | thrust detected / liftoff |
| 3 → 4 | thrust cutoff / burnout   |
| 4 → 5 | apogee detected           |
| 5 → 6 | touchdown detected        |


DRIVERS (raw)
    ↓
PROCESSING (physics clean data)
    ↓
ESTIMATION (EKF)
    ↓
FLIGHT STATE (decisions)
    ↓
ACTUATORS (execution)

mpu6050 (raw int16)
    ↓
imu_processing (float + corrected frame)
    ↓
attitude_ekf
